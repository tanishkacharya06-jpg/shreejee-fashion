SHREEJEE FASHION — START HERE (v1.0.11)
=====================================

FIRST-TIME SETUP
1) Install Python 3.10+ from https://www.python.org/downloads/ and enable “Add Python to PATH”.
2) Extract this ZIP into a normal folder.
3) If upgrading an existing Shreejee installation, back up its `store.db` and `static/uploads/` first. Copy those two into this extracted project before the first startup to retain products, customers, orders, and uploaded images. Do not overwrite your backup. Startup migrations are designed to add missing fields/tables without deleting existing records.
4) Open the extracted folder in File Explorer, click the address bar, type `cmd`, and press Enter.
5) Install dependencies once:
       py -m pip install -r requirements.txt
6) Start the website by double-clicking `app.py`, or run:
       py app.py
7) The browser opens the temporary Cloudflare URL automatically once the tunnel is ready (the local http address is not opened). Keep the terminal window open.

ONE-CLICK CLOUDFLARE
- app.py attempts to start a temporary Cloudflare Quick Tunnel automatically.
- If cloudflared.exe is not present, it attempts to download the official Windows binary.
- Copy the https://....trycloudflare.com URL displayed in the terminal and open it on your phone.
- The temporary public URL changes after a restart. Internet access is required.
- If the automatic download is blocked, install the official cloudflared tool and restart app.py.
- No .bat file is required. Closing the app.py window stops the web server and tunnel.

VERSION 1.0.10 DIAGNOSTICS
- Visit /health on the local/public store URL to confirm the Flask app responds. A working install returns JSON with ok=true and version 1.0.10.
- If you see a JSON response with code 10005 and “Method Not Allowed”, verify you opened the https://....trycloudflare.com/ homepage printed in the terminal, not a Cloudflare API URL or a submit-only page. This app does not send requests to the Cloudflare REST API.

SECURITY & BACKUPS
- On first run, a private `.secret_key` file is generated automatically unless `SHREEJEE_SECRET_KEY` is supplied in the environment.
- Back up `store.db` and `static/uploads/` before upgrades. Do not share the database or `.secret_key` file publicly.
- For public deployment, use HTTPS, set a long random `SHREEJEE_SECRET_KEY`, change starter admin passwords, and use a production WSGI server.
- Never put real payment secrets in source files or share card PINs, CVVs, UPI PINs, or bank passwords.

For older feature details, read README.md and the historical CHANGELOG files. The ZIP intentionally excludes customer data and private keys.
