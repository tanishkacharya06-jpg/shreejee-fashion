Shreejee Fashion — website reliability fixes

- Improved Android gallery return handling for single and multi-select URIs so selected photos return to the WebView file input.
- Gallery upload now accepts generic MIME types and filenames reported by Android photo providers, then decodes/converts image content before upload.
- Manage Products → Catalogue rows are clickable; View, Edit, Hide/Publish and Delete controls retain their normal actions.
- Android Back skips login/reset pages and completed product create/edit forms instead of reopening stale workflows.
- Remote app-icon downloads retry after a temporary network failure and only mark the image loaded after a successful fetch.
- Updated website static cache keys to v1.0.22.
